# QUY TRÌNH ĐẢM BẢO CHẤT LƯỢNG (QA PLAN) - NHÓM 14

- **Người phụ trách:** Phạm Nhi Linh (V4 - QA)
- **Mục tiêu:** Đảm bảo quy trình làm việc chuẩn Gitflow và chất lượng mã nguồn.

## 1. Quy chuẩn Commit Message

- `Feat`: Tính năng mới
- `Fix`: Sửa lỗi
- `Docs`: Cập nhật tài liệu
- `Test`: Thêm/sửa kịch bản test
- `Chore`: Cấu hình hệ thống/thư viện

## 2. Quy trình Review Code (Pull Request)

- Mọi Pull Request bắt buộc phải trỏ về nhánh `dev`.
- Phải có ít nhất 1 phê duyệt (Approval) từ Trưởng nhóm (V1) mới được Merge.
