1. Hệ thống Biến Thiết kế (Design Tokens - frontend/css/tokens.css)

Hỗ trợ chuyển đổi tức thì giữa 02 chủ đề: Giao diện Sáng tiêu chuẩn (Forest Teal & Warm Sand) và Chế độ Người cao tuổi / Tương phản cao ([data-theme="accessible"] - Nền đen chữ vàng rực, cỡ chữ ≥ 20px, nút bấm ≥ 46px đạt chuẩn WCAG 2.1 AA).

:root {
  --color-primary: #115e59;          /* Xanh rừng chủ đạo (Wheel the World Style) */
  --color-secondary: #f6efe6;        /* Kem ấm hộp tìm kiếm */
  --color-verified: #facc15;         /* Nhãn vàng Accessibility Verified */
  --font-size-base: 17px;            /* Cỡ chữ tiêu chuẩn */
  --touch-target-min: 46px;          /* Kích thước vùng chạm tối thiểu >= 44px */
}
[data-theme="accessible"] {
  --color-bg-main: #000000;          /* Nền đen tương phản cao */
  --color-text-main: #ffff00;        /* Chữ vàng rực (>7:1 AAA) */
  --color-primary: #00ff66;          /* Nút bấm xanh dạ quang */
  --font-size-base: 20px;            /* Phóng to chữ cho người cao tuổi */
}

2. Cấu trúc Khung Giao diện 03 Trang Chính & Đồng bộ Hợp đồng API v0.1

1. Trang Danh sách & Lọc (index.html)
• Kết nối API: GET /api/search.php
• Tham số: page, limit, keyword, has_wheelchair.
• Tích hợp Video giới thiệu & Dải đánh giá 4.9★.
2. Trang Chi tiết Hạ tầng (detail.html)
• Hiển thị thông số đo đạc thực tế: Độ dốc ramp_slope (%), Cửa rộng door_width (cm), Thang máy, Tay vịn WC.
• Đánh giá xác thực từ cộng đồng.
3. Trang Đặt & Giữ chỗ (booking.html)
• Kết nối API: POST /api/book.php
• Khớp Request JSON: destination_id, booking_date, quantity, special_note.
• Tích hợp Countdown Timer 15 phút.
